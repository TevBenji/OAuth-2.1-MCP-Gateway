# Product Overview

## OAuth 2.1 MCP Gateway

The OAuth 2.1 MCP Gateway is an authentication and authorization proxy that transforms the Model Context Protocol (MCP) ecosystem from insecure static API keys to enterprise-grade OAuth 2.1 authentication. The gateway acts as a security layer between MCP clients (AI agents like Claude, ChatGPT, Cursor) and MCP servers.

## Core Value Proposition

- **Security Transformation**: Converts 98% of exposed, unauthenticated MCP servers to OAuth 2.1 secured endpoints
- **Separation of Concerns**: Gateway handles OAuth complexity while MCP servers become simple stateless resource servers
- **Enterprise Ready**: Multi-tenant architecture with audit logging, compliance features, and centralized policy enforcement
- **Developer Experience**: Zero-configuration setup with comprehensive documentation and SDKs

## Key Features

- OAuth 2.1 authorization server with mandatory PKCE
- Multi-tenant architecture with complete isolation
- Edge computing deployment for sub-10ms global latency
- Enterprise security features (audit logging, session management, risk scoring)
- Integration with major identity providers (Auth0, Okta, Microsoft Entra, Keycloak)
- Comprehensive developer tools and documentation

## Target Market

- Enterprise developers securing MCP deployments
- SaaS providers needing multi-tenant MCP authentication
- Organizations requiring compliance (PCI-DSS, HIPAA, GDPR)
- Development teams wanting secure MCP integration without OAuth complexity

## Business Model

- Freemium SaaS with usage-based pricing
- Free tier: 10K requests/month, 3 MCP servers
- Paid tiers: Pro ($299/month), Business ($999/month), Enterprise (custom)
- Revenue drivers: request volume, tenant count, enterprise features
